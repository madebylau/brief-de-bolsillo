# Brief de bolsillo

Un generador de briefs creativos para diseñadores. Cada reto incluye una idea, un sector, un público, un formato, un tono y una limitación para ayudar a arrancar un proyecto.

## Funciones

- Genera briefs aleatorios sin repetir el anterior.
- Guarda, consulta, copia y elimina briefs.
- Conserva los guardados en el navegador con `localStorage`.
- Diseño adaptable a móvil y escritorio.
- No necesita cuenta, servidor ni claves de API.

## Abrir el proyecto

Descarga o clona el repositorio y abre `index.html` en un navegador. Para usar la función de copiar en todos los navegadores, sirve los archivos desde un entorno local o desde GitHub Pages.

## Publicarlo con GitHub Pages

1. Sube `index.html`, `styles.css`, `app.js` y `README.md` a la rama principal del repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, elige la rama principal y la carpeta `/ (root)`.
4. Guarda los cambios. GitHub mostrará el enlace de la web en esa misma sección.

Los briefs guardados viven en el navegador de cada visitante y no se sincronizan entre dispositivos.
